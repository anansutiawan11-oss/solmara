SOLMARA — an original open-world crime game in a sun-soaked coastal city: steal cars, outrun the Solmara PD through a 5-star wanted system, and run seven story missions from wheelman to street legend. A procedural golden-hour city with traffic, pedestrians, police chases, a helicopter, combat, a HUD with a live minimap, radio stations, and saves. Built with three.js, no build step, plays offline in a desktop browser.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
